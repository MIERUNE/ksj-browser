# Contract: 行政区域データ更新ツール

## 目的

国土数値情報の N03 データページから「地域/年/ファイル名」を抽出し、`gyousei_kuiki.json` を再生成する。

## 入力

- 対象ページ URL（デフォルトは N03 最新版ページ）

## 出力

- `ksj/data_collections/gyousei_kuiki.json`（上書き）

## 振る舞い

- Web ページから行を抽出し、年度 → 地域 → ファイル名に整形する
- 地域名は既存コレクション表記へ正規化する
- 同一年・同一地域の複数候補がある場合は SHP 優先・無ければ GML
- 失敗時はエラー終了し、原因がわかるメッセージを出す

## 期待される終了コード

- `0`: 成功
- `1`: ネットワーク/HTTP エラー
- `2`: パース失敗（期待するテーブル/列が見つからない）
- `3`: 出力書き込み失敗
