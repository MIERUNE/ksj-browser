# 展開したファイルからレイヤーを追加する

## 選択した方式

利用者は「ZIPを一時取得・展開し、通常のファイルとして保存してマップへ追加する」を選択した。ZIPを保存してVSIで参照する方式を置き換える。単体ファイルの直接配布だけに限定すると同梱カタログを利用できないため採用しない。

## 動作

- 初回だけの保存先選択と記憶、ブラウザ・ドラッグ・メッシュ追加の操作は維持する。
- ZIPは一時領域へ取得し、全ファイルを展開してから保存先へ確定する。Shapefile付属ファイル、GMLスキーマ、説明書、元のフォルダ構成を保持する。
- 入れ子ZIPも展開する。入れ子の展開先はZIP名に `.files` を付けたフォルダとする。新規取得したZIPは作業完了・中止・失敗時に削除する。
- レイヤーの参照は通常のローカルファイルパスとし、再追加・再描画・プロジェクト再読込では再取得しない。
- URLごとの保存と排他制御を維持する。旧方式で取得済みのZIPがあれば通信せず展開し、旧レイヤーのために元ZIPは削除しない。既存レイヤーの参照は自動変更しない。

## 実装と制約

Python 3.9、QGIS 3.40以上、追加依存なし。QGIS 3.42.1 / Qt 5.15.2で検証する。展開はストリームで行い、CRC検証・キャンセルに対応する。パス逸脱、シンボリックリンク、同名衝突、深すぎるZIP入れ子は確定せずエラーにする。展開失敗や空き容量不足では一時ファイルを掃除し、既存データを上書きしない。

## 検証

実HTTP取得回数、Shapefileの属性・形状、入れ子ZIP、UTF-8/CP932名、展開失敗・中止・不正パス、同時取得、ブラウザ/メッシュURI、保存後の移動・再読込をテストする。既存のドラフトPR #10へ反映する。
