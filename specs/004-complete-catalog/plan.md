# 国土数値情報の全データ対応

目的: 公式サイトで公開される全データをQGISから把握・アクセスできるようにする。

構成: 公式分類→データセット→年度→地域・メッシュ・河川等→配布ファイル→内部レイヤー。
単一地域に複数ファイルがあっても省略せず、配布URLは公式ページから取得する。
旧形式・QGISで直接読めないファイルも公式ページとダウンロードへの導線を持つ。
公開元の欠落・取得失敗は明示し、成功したように扱わない。

Python 3.9、標準ライブラリ、既存QGIS/GDALを利用する。新しい依存は導入しない。

## 実装

- [x] `scripts/update_catalog.py`: 公式分類と詳細ページ・旧版を収集。
  HTML表のヘッダ、地域、年度、形式、測地系、容量、URLを保持。
  キャッシュと再試行、再現可能なJSON、取得失敗時の既存成果物保護を実装。
  テスト: コメント除外、相対URL、rowspan、複数配布、履歴リンク、失敗時の非上書き。
- [x] `ksj/catalog.py`, `ksj/catalog/`: インデックスとデータセット別の遅延読み込み。
  公式データの網羅数と取得エラーを記録して全対象を監査する。
- [x] `ksj/browser.py`: 分類・年度・地域・形式を選択できるブラウザ。
  公式説明・利用条件・直接ダウンロード、取得エラー表示を追加。
  テスト: 全国、都道府県、メッシュ、河川、同地域複数ファイル、オフライン起動。
- [x] `ksj/zip_scanner.py`: GMLがツリーで落ちる不具合を修正。
  ラスタ、CSV、入れ子ZIP、直接読めない旧形式もアクセス可能にする。
  テスト: GML/ラスタ/CSV、入れ子ZIP、サイドカーファイル、読み込みとドラッグ。
- [x] READMEを更新。実QGIS環境でテスト・カバレッジ・lint・代表配布の読み込みを確認。

## 完了条件

公式一覧および関連する旧版・旧形式の対象を取得済み一覧と照合する。
データ項目数だけでなく各配布URLの保持を確認する。
読み込み形式ごとの実データ確認を行い、公開元の制約があれば記録する。
単なる公式トップへのリンク追加や3種類の拡張だけでは完了としない。
